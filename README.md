# Amatu Sheets

Spreadsheet di browser yang memadukan alur kerja Google Sheets dengan fitur lanjutan Microsoft Excel.
Live: https://liemyo.github.io/spreadsheet/

## Fitur
- Grid canvas cepat: freeze panes, gabung sel, sembunyikan/ubah ukuran baris & kolom, zoom, isi otomatis (fill handle), salin/tempel dengan format, tempel spesial.
- 400+ fungsi: matematika, statistik, logika, teks, tanggal, keuangan, teknik, database, plus XLOOKUP, LET, LAMBDA, MAP/REDUCE/SCAN, FILTER, SORT, UNIQUE, SEQUENCE, QUERY, SPARKLINE, IMAGE, TERBILANG.
- Array dinamis dengan spill dan referensi `A1#`, rentang bernama, referensi lintas sheet.
- Format angka gaya Excel (mata uang Rp, akuntansi, tanggal, kustom), format bersyarat (warna tunggal, skala warna, bilah data, set ikon), warna bergantian.
- Validasi data: dropdown chip, kotak centang, angka/tanggal/teks/rumus kustom.
- Filter, urutkan, hapus duplikat, pisahkan teks, isi kilat (Ctrl+E), Goal Seek, tabel pivot, statistik kolom, cari & ganti.
- Diagram (kolom, batang, garis, area, kombo, lingkaran, donat, sebar, radar).
- Impor/ekspor .xlsx, .ods, .csv, .tsv, .json; cetak/PDF; tautan bagikan; histori versi.
- Tema Kaca Terang, Kaca Gelap, Aurora, Samudra, Klasik, Hijau Excel, Grafit dengan efek liquid glass.

Data tersimpan di perangkat (IndexedDB). Tanpa build step — ES modules murni.
